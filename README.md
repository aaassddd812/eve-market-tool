# EVE 市场辅助工具

EVE Online（欧服宁静）一站式辅助工具：市场中心、个人中心、3D 星图、击杀记录、旗舰跳跃规划、模拟装配。
纯原生 HTML/CSS/JS 实现，无框架依赖；后端为两个纯标准库 Python 服务。

**在线使用：<https://eve.navexor.top/>**

## 功能总览

- **市场中心**：对 eve-overview.net 市场页的前端复刻。完整物品分类树（约 2 万个物品，官方中文名）、
  实时买卖订单（价格精确到 0.01，点击复制可直接粘贴进游戏）、价格走势与历史图表、订单簿排序与交易中心筛选、
  收藏 / 最近浏览、`#type=34` 形式的可分享链接与大量快捷键
- **个人中心**：绑定 ESI 后读取角色身份、钱包、资产（含空间站估值）、合同（交换 / 拍卖 / 快递，含估值与出价记录）、
  市场订单、技能与技能队列、克隆与植入体、钱包流水、声望、工业任务、通知、采矿与战斗记录
- **3D 星图**：three.js 还原旧版游戏 3D 星图（5485 星系 / 6989 星门），12 种着色方式（安全等级、主权、
  势力战争、实时击杀 / 跳跃 / 入侵等）、星系与星域详情、ESI 路线规划、我的位置、实时击杀推送与疑似会战提醒
- **击杀记录（KB）**：自建服务收录新伊甸全部击杀邮件（近 30 天入库 + zKillboard 实时流 + 更早记录实时查询），
  全宇宙击杀页、人物 / 军团 / 联盟统计与排行榜、击杀详情（装配分组、掉落估值、攻击者列表），
  价值按吉他海 4 中间价估算
- **旗舰跳跃规划**：航母 / 无畏 / 超旗 / 泰坦 / 黑隐 / 战略货舰等的跳跃路线（光年、燃料、冷却与疲劳逐跳列出），
  避开高安，支持按角色技能计算；停靠要求可选 NPC 空间站 / 含玩家建筑 / 优先可停靠，
  含军团联盟内部建筑（角色建筑搜索发现）
- **模拟装配**：与游戏相同 dogma 规则的装配模拟器——高 / 中 / 低槽、改装件、T3 子系统、无人机、植入体，
  DPS / EHP / 电容稳定 / 速度 / 锁定等全套属性，资源与技能检查，EFT 导入导出，装配分享链接
- **ESI 授权**：纯前端 PKCE——令牌只存在你的浏览器，本站服务器接触不到；解绑即清除，可随时在 CCP 撤销
- **手机端适配**：侧栏抽屉、卡片式击杀列表、全屏弹窗、刘海屏安全区

## 目录结构

```
eve-overview-clone/          # 前端 + 后端服务（详见其 README.md）
├── index-v2.html            # 入口页
├── js/                      # 按需加载的各功能模块
├── css/                     # 样式
├── *.json                   # 由 CCP 官方 SDE 生成的静态数据（星图 / 装配 / 中文名等）
├── server/esi_service.py    # 公开应用配置 + 玩家建筑共享缓存（不接触令牌）
├── server/kb_service.py     # 击杀记录服务（EVE Ref 存档 + R2Z2 实时流）
└── server/eve.navexor.top.conf  # nginx 配置
build_*.mjs / build_catalog.mjs  # 从 SDE / ESI 生成静态数据的脚本
```

完整功能说明、快捷键、数据来源与部署方法见 **[eve-overview-clone/README.md](eve-overview-clone/README.md)**。

## 本地运行

```bash
cd eve-overview-clone
python -m http.server 8899 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8899/index-v2.html
```

不依赖任何构建步骤；后端服务为可选（仅击杀记录、建筑缓存等功能需要）。

## 数据来源

- [ESI](https://esi.evetech.net/)（CCP 官方接口）：市场订单、价格历史、角色数据（需授权）、主权、路线等
- [CCP 官方 SDE](https://developers.eveonline.com/static-data.html)：星图坐标、装配属性、官方中文名等静态数据
- [zKillboard](https://zkillboard.com/) / EVE Ref：击杀邮件（历史存档 + R2Z2 实时推送）
- 物品图标来自网易 EVE 图床
