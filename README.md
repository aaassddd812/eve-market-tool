# EVE 市场辅助工具

EVE Online（欧服宁静）一站式辅助工具：市场中心、个人中心、3D 星图、击杀记录、旗舰跳跃规划、模拟装配。
纯原生 HTML/CSS/JS 实现，无框架依赖；后端为两个纯标准库 Python 服务。

**在线使用：<https://eve.navexor.top/>**

## 功能总览

- **市场中心**：对 eve-overview.net 市场页的前端复刻。完整物品分类树（约 2 万个物品，官方中文名）、
  实时买卖订单（价格精确到 0.01，点击复制可直接粘贴进游戏）、价格走势与历史图表、订单簿排序与交易中心筛选、
  收藏 / 最近浏览、`#type=34` 形式的可分享链接与大量快捷键；行情指标（成交天数、波动、买卖盘比、偏离均价）；
  自选看板（收藏物品的涨跌、30 天走势、五个交易中心比价与一句话结论）与价格提醒
- **个人中心**：绑定 ESI 后读取角色身份、钱包、资产（含空间站估值）、合同（交换 / 拍卖 / 快递，含估值与出价记录）、
  市场订单、技能与技能队列、克隆与植入体、钱包流水、声望、工业任务、通知、采矿与战斗记录；
  改单小助手（被压价提示与建议改价）、订单变化报告与后台盯盘，资产净值趋势、清仓小助手（每种物品去哪卖、卖收单还是挂单）
- **3D 星图**：three.js 还原旧版游戏 3D 星图（5485 星系 / 6989 星门，宁静 / 晨曦可切换游戏 2D 星图排布），12 种着色方式（安全等级、主权、
  势力战争、实时击杀 / 跳跃 / 入侵等）、星系与星域详情、ESI 路线规划（支持多个途经点，自动排最短顺序或按指定顺序，可粘贴游戏里复制的地点一次导入，绑定 ESI 后自动走你能用的跳桥）、我的位置、实时击杀推送与疑似会战提醒
- **击杀记录（KB）**：自建服务收录新伊甸全部击杀邮件（近 30 天入库 + zKillboard 实时流 + 更早记录实时查询），
  全宇宙击杀页、人物 / 军团 / 联盟统计与排行榜、击杀详情（装配分组、掉落估值、攻击者列表），
  列表价值按吉他海 4 中间价估算
- **旗舰跳跃规划**：航母 / 无畏 / 超旗 / 泰坦 / 黑隐 / 战略货舰等的跳跃路线（光年、燃料、冷却与疲劳逐跳列出），
  避开高安，支持按角色技能计算，可加多个途经点；停靠要求可选 NPC 空间站 / 含玩家建筑 / 优先可停靠，
  含军团联盟内部建筑（角色建筑搜索发现）
- **模拟装配**：与游戏相同 dogma 规则的装配模拟器——高 / 中 / 低槽、改装件、T3 子系统、无人机、植入体，
  DPS / EHP / 电容稳定 / 速度 / 锁定等全套属性，资源与技能检查，EFT 导入导出，装配分享链接
- **主权规划**：按星系 / 星座 / 星域规划主权中心升级件，模拟电力、劳动力（含跨星系导出 / 导入 / 中转）与燃料试剂，一键规划只需选天钩和升级件、劳动力运输与产出件自动配；宁静服可用 ESI 读取军团主权中心与天钩的实际配置并导入
- **深渊市场**：按 MutaMarket 数据浏览在售深渊装备（按属性范围、金条 / 棕条、价格、估价筛选排序），装备详情含模型估价与可信度、相似装备搜索、与各原装备属性和价格对比；粘贴游戏物品链接或在突变属性弹窗中查单件估价；MutaMarket 没有的装备、装配自定义属性用本站按同样算法训练的模型估价，资产里的深渊装备可一键估价（宁静服）
- **制造**：任意产品的材料、安装费、时间、发明成本与利润（解码器对比、95% 把握发明次数、ME 影响、研究与拷贝费用），利润排行（按交易中心行情的综合评分与成交量筛选，可只看技能够造 / 我有的蓝图）、制造地点、NPC 蓝图查询；制造规划把多个产品一起算——组件逐级自制、扣除库存、分批、发明进度、
  按各角色技能与进行中任务分配产线的时间轴，行星材料一键跳到行星工业规划，并可按现有库存反推能造什么；没有蓝图权限时可粘贴游戏蓝图列表导入
- **虫洞**：查任意虫洞星系的等级、天象效果、固定出口、行星，以及近 30 天击杀、活跃时段与推测住户；虫洞活跃度排行、全部虫洞类型、天象数值表、虫洞质量计算，以及 EVE-Scout 的席拉 / 图尔努尔实时连接（按跳数找最近入口）
- **交易中心比价**：市场详情里比较五大交易中心的卖价 / 收价 / 订单量 / 日均成交，计算跨中心倒卖的税后利润（按技能与税费，可按体积计运费）、可做数量、预计利润与每立方利润；「倒卖排行」把所有物品放在一起按利润排行；绑定 ESI 后可扫描或手动添加你有权限的玩家建筑市场，一起参与比价、排行和订单簿
- **物品估值**：所有估值处可切换吉他 / 四族贸易中心 / 全宇宙，同时给出最低卖价与最高收价（默认吉他）
- **教程**：图文 Wiki（新伊甸学院、BWIKI、萌娘百科、EVE University 全文译文，均注明出处）+ 分类视频（站内嵌入 B 站 / YouTube）
- **ESI 授权**：纯前端 PKCE——令牌只存在你的浏览器，本站服务器接触不到；解绑即清除，可随时在 CCP 撤销
- **中英文界面**：右上角一键切换；默认语言按浏览器语言与时区判断（中文环境显示中文，其余显示英文），游戏内名称（物品、星系、NPC 等）用 CCP 官方英文名，搜索也可输入英文；教程里的中文 Wiki 正文保持中文
- **手机端适配**：侧栏抽屉、卡片式击杀列表、全屏弹窗、刘海屏安全区

## 目录结构

```
eve-overview-clone/          # 前端 + 后端服务（详见其 README.md）
├── index-v2.html            # 入口页
├── js/                      # 按需加载的各功能模块
├── css/                     # 样式
├── *.json                   # 由 CCP 官方 SDE 生成的静态数据（星图 / 装配 / 中文名等）
├── server/esi_service.py    # 公开应用配置 + 玩家建筑共享缓存（不接触令牌）
├── server/kb_service.py     # 击杀记录服务（EVE Ref 存档 + R2Z2 实时流）
└── server/eve.navexor.top.conf  # nginx 配置
build_*.mjs / build_catalog.mjs  # 从 SDE / ESI 生成静态数据的脚本
build_names_en.py            # 生成英文版用的官方中英名称对照表 i18n/names-en.json
```

完整功能说明、快捷键、数据来源与部署方法见 **[eve-overview-clone/README.md](eve-overview-clone/README.md)**。

## 本地运行

```bash
cd eve-overview-clone
python -m http.server 8899 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8899/index-v2.html
```

不依赖任何构建步骤；后端服务为可选（仅击杀记录、建筑缓存等功能需要）。

## 数据来源

- [ESI](https://esi.evetech.net/)（CCP 官方接口）：市场订单、价格历史、角色数据（需授权）、主权、路线等
- [CCP 官方 SDE](https://developers.eveonline.com/static-data.html)：星图坐标、装配属性、官方中文名等静态数据
- [zKillboard](https://zkillboard.com/) / EVE Ref：击杀邮件（历史存档 + R2Z2 实时推送）
- 物品图标来自网易 EVE 图床
