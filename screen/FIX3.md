# 任务3：大屏四处改动（/opt/eve/screen/）

## 1. 删除顶部"今日识别代理"卡片
大屏顶部数字卡里去掉这张（后端 proxied_count 字段保留不动）。

## 2. 修复省份排行只有两个省的问题
先诊断原因再修。最可能：IP 归属地用 ip-api.com 单条查询（限 45 次/分），IP 积压严重，绝大多数还没解析。
修法：改用批量接口 POST http://ip-api.com/batch，body 为 JSON 数组（每批最多 100 个 IP，字段 ?fields=status,country,regionName,city,query），每分钟最多 15 批 = 1500 IP/分。启动回放与运行期新增 IP 都进批量队列，每 4 秒凑批发送（不满 100 个也按现有数量发，但每分钟不超过 15 批）。解析结果照旧写 sqlite 缓存。验证：启动后 2 分钟内 provinces 数量应超过 20。

## 3. 统计口径改为"滚动最近 24 小时"
顶部数字卡（访客/请求/在线/每秒/峰值）、省份、国家、热门页面、服务器分布、新旧域名、访客去重——全部按"当前时刻往前 24 小时"计算。界面文字"今日"改为"近24小时"。当前在线、每秒请求、实时访问流的定义不变。

## 4. 底部小时图：近24小时 + 今天/昨天双色 + hover 联动
- 横轴 = 最近 24 个整小时（从最早到当前小时），每根柱子是那一小时的访客数（或请求数，保持现在的指标）
- 属于"今天"的小时用正常色，属于"昨天"的小时用淡色（同色系低不透明度），同一张图表内连续排列；跨天交界处 x 轴标签标注日期（如 "昨天 23时" / "今天 0时"，其余只标 "N时"）
- 交互：图表上方放两个小图例"今天""昨天"。鼠标 hover 到今天任意柱子（或图例）→ 昨天的柱子整体隐藏；hover 昨天 → 今天隐藏；移开恢复正常。图例也可点击固定切换。
- 用 ECharts 原生能力实现最简方案即可（例如两条独立 series 拼在同一个 category 轴上，各自 itemStyle 控制深浅，hover 某条 series 时把另一条 graphic/series 的 opacity 置 0）。
