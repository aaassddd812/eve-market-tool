EVE Market开放 API v1

开放 API

本站对外提供的只读接口：吉他市场价格、蓝图合同价、制造成本与利润、成本指数、击杀记录、会战、排行与实体统计、按舰船的阵亡装配。数据与网站页面相同，免注册、免密钥，可以直接在浏览器或你的程序里调用。

基础地址
格式JSON（UTF-8），支持 gzip
频率限制每 IP 每分钟 1000 次
跨域允许任意来源（CORS *）

通用约定

      
频率限制

      
按来源 IP 计算，令牌桶容量 1000，每秒恢复约 17 次额度。多数接口每次消耗 1 次，标注了「消耗 N 次」的接口一次扣 N 次。每个响应都带有：

      

        
响应头说明

        
X-RateLimit-Limit每分钟额度（1000）

        
X-RateLimit-Remaining当前剩余额度

        
Retry-After仅 429 时出现，需要等待的秒数

      

      
错误

      
出错时返回对应的 HTTP 状态码和统一的错误对象：

      
{"error": {"code": 400, "message": "缺少 types"}}

      

        
状态码含义

        
400参数缺失或无效

        
404接口不存在，或找不到对应的击杀 / 实体

        
429请求过于频繁，按 Retry-After 等待后重试

        
500服务器内部错误

      

      
其他

      
时间均为 UTC，ISO 8601 格式（如 2026-10-17T08:05:44Z），参数里的时间戳为 Unix 秒。金额单位为 ISK。击杀数据只保留最近约 30 天（见 /status 的 retention_days），更早的记录请使用 zKillboard。返回里的 names 是本次结果中出现的人物 / 军团 / 联盟 ID 到名称的映射。

      
数据来自 CCP ESI、zKillboard 与 EVE Ref，仅供参考。请合理控制调用频率；需要更高额度可以在 GitHub 提 issue。
