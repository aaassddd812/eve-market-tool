# EVE 总览 · 市场中心 — 前端复刻版

对 `https://www.eve-overview.net/index/index?server=tranquility&ids=1922_1923_144992&_region=10000002&action2=market`
（宁静服务器 · 伏尔戈星域 · 伊甸币 市场页）的前端 1:1 复刻，纯原生 HTML/CSS/JS 实现，无任何框架依赖。

## 运行方式

```bash
cd eve-overview-clone
python -m http.server 8899 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8899/index-v2.html
```

也可以用任意静态服务器（VS Code Live Server、nginx 等）。直接双击 index-v2.html 也可以运行，
但通过 HTTP 服务打开更接近原站环境。

## 文件结构

```
eve-overview-clone/
├── index-v2.html        # v2 页面结构（导航/侧栏/工具栏/详情/市场数据表）
├── css/modern-style.css # 全部样式
├── js/modern-app.js     # 数据 + 交互逻辑
├── catalog.json         # 物品目录（含官方中文名称）
└── type-names-zh.json   # 物品中文名数据
```

## 复刻内容

- **顶部导航**：EVE 总览 Logo、市场中心（当前激活）、忠诚点(LP)、虫洞、行星工业、成本计算、
  订单与资产/合同查询/更多（悬停弹出下拉菜单）、登陆、服务器切换下拉、分隔线、我要订阅（红色）、
  主题按钮、省略号菜单
- **左侧物品菜单**（380px）：物品菜单/物品收藏列表两个 Tab、收起按钮、搜索框（实时过滤）、
  完整物品分类树（可展开/收起/选中，当前选中"伊甸币"，悬停显示操作图标）
- **工具栏**：数据源固定为 ESI 欧服宁静（Tranquility）、星域下拉（伏尔戈）、搜索框、在线人数（曙光/晨曦/宁静）、绑定 ESI、合同估值
- **物品详情**：64px 物品图标（外链官方图床）、四个蓝色操作图标、前后翻页箭头、
  体验新版市场中心链接、更新价格数据按钮（带加载动画，会刷新"更新时间"）、我的库存/军团库存、玩家建筑市场
- **市场数据**：详情/物品分组/个人收藏分组 + 实时卖家/买家订单、价格历史表格、价格历史图表；绑定 ESI 后可读取角色身份、钱包、位置、舰船、技能、技能队列、资产、合同、角色订单、克隆、植入体、钱包流水、交易记录、声望、工业任务、通知和采矿记录等角色数据
- **合同价值估算**：选择角色合同后读取合同物品，使用当前区域的最高求购价和最低出售价格计算收购价、出售价，并比较合同价格与两种市场估值；无行情的物品会单独标记，不按 0 误算
  两级 Tab；卖家/买家两张数据表（数量100px/价格140px/订单总价格140px/地点自适应/订单日期135px，
  表头 50px、行高 39px、底部统计行 40px）
- **首屏加载遮罩**：模拟原站"页面加载中，请稍候..."加载态

## 数据说明

目录来自 ESI 市场组接口，`catalog.json` 中的物品名称来自 ESI `/universe/types/{type_id}/?language=zh`，当前目录包含 19,957 个物品的官方中文名称。
点击物品后，页面直接请求 ESI 的区域订单、历史价格、全服基准价和地点名称接口；不会再使用内嵌的静态买卖单快照。
物品图标来自网易 EVE 图床（https://image.evepc.163.com/Type/{type_id}_64.png），需联网加载。

## 与原站的已知差异

- 在线人数仍为页面快照（原站实时刷新）
- 合同相关 Tab 仍是原页面的占位入口；可通过右上角“合同估值”打开已接通的合同工具
- ESI 授权需要在官方 [EVE Developers](https://developers.eveonline.com/) 注册应用，将绑定弹层提示的回调地址填入应用配置，再粘贴 Client ID。页面会生成授权链接，登录完成后把地址栏中的完整回调地址粘回工具。OAuth 使用 PKCE，access/refresh token 只存储在浏览器 localStorage，解绑会清除令牌
- 省略号菜单、更多菜单的下拉项为快照可见项
