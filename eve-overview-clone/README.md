# EVE 总览 · 市场中心 — 前端复刻版

对 `https://www.eve-overview.net/index/index?server=tranquility&ids=1922_1923_144992&_region=10000002&action2=market`
（宁静服务器 · 伏尔戈星域 · 伊甸币 市场页）的前端 1:1 复刻，纯原生 HTML/CSS/JS 实现，无任何框架依赖。

## 运行方式

```bash
cd eve-overview-clone
python -m http.server 8899 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8899/index-v2.html
```

也可以用任意静态服务器（VS Code Live Server、nginx 等）。直接双击 index-v2.html 也可以运行，
但通过 HTTP 服务打开更接近原站环境。

## 交互与快捷键（v3）

- **目录**：分类按需渲染（展开时才生成子节点），支持 ↑↓←→ 键盘导航、一键全部折叠；选中物品后自动展开所在分类并定位
- **搜索**：按名称 / 分类 / Type ID 搜索，结果按匹配度排序并高亮，带物品图标；`Enter` 打开第一项，`Esc` 清空
- **收藏 / 最近浏览**：侧栏独立标签页，保存在浏览器本地
- **订单簿**：价格精确到 0.01，表头可排序，点击行复制价格（可直接粘贴进游戏），可只看交易中心（吉他海4 等）订单，最优价高亮
- **价格走势 / 历史**：30 天 / 90 天 / 180 天 / 1 年范围切换；图表跟随主题配色
- **地址栏**：`#type=34` 形式的可分享链接，支持浏览器前进后退
- **布局**：侧栏收起后让出宽度、可随时展开；移动端目录为抽屉；主题跟随系统并可手动切换

## 个人中心（v3.1）

- **侧栏**：与市场中心一致，可收起（`[`）/展开，移动端为抽屉；「空间站资产」分组可折叠，按估值排序并显示每个位置的物品数与卖价估值
- **资产估值 / 空间站**：「资产估值」显示总估值与各空间站汇总（点击进入）；选中某个空间站时，与市场中心选中物品一样，只显示该站的物品与该站估值，可筛选物品
- **位置名称**：装在舰船/集装箱里的资产会沿 `location_id` 向上找到真正所在的空间站；NPC 空间站、星系、NPC 军团、NPC 角色显示官方中文名（`npc-names-zh.json`），玩家军团/联盟/建筑等玩家自定义名称保留原名
- **资产估值**：可选交易中心或全宇宙（默认吉他海4，见下文「物品估值来源」），分别按**最低卖价**和**最高收购价**估值；行情在本机缓存，可「刷新行情」；蓝图副本与无行情物品不计入。
  估值卡片另给税后金额（挂卖单扣销售税 + 中介费，卖给收单与「我的卖单」全部成交只扣销售税），工具栏的税费按钮打开「交易税费」设置
- **资产读取**：读取全部分页
- **技能**：侧栏「技能」按游戏分组列出全部 512 个技能（`skill-data.json`），显示已训练 / 生效等级（Alpha 克隆受限时区分）、技能点、下一级所需技能点与训练倍数，未学的技能灰显；
  顶部汇总总技能点、未分配技能点、已学技能数，并显示训练队列（剩余时间与当前进度，需要 esi-skills.read_skillqueue.v1）；可按中英文搜索、按已学 / 未满级 / 未学筛选，分组展开状态保存在本机
- **合同查询**：读取角色合同（ESI 保留最近 30 天），按游戏内类别「物品交换 / 拍卖 / 快递」分类，可按状态（待接受、进行中、已完成、已过期、已取消等）和角色（我发起 / 我接受 / 指派给我）筛选；点开合同可查看物品清单、交易中心最低卖价与最高收购价估值，以及合同价与两种估值的差额和比例。收购合同比较报酬与索取物品价值；拍卖显示出价记录；快递显示报酬、单位体积报酬与抵押金覆盖率

官方中文名称表由 `build_npc_names.mjs` 从 CCP 官方 SDE 生成（生成时会用 ESI 校验全部 5210 个 NPC 空间站的拼名规则）：

```bash
# 下载并解压 https://developers.eveonline.com/static-data/eve-online-static-data-latest-jsonl.zip
node build_npc_names.mjs <解压目录> --verify
```

## 星图（v7 · 旧版 3D 星图）

- **布局**：使用 CCP SDE 的三维坐标 `position`，以 three.js（WebGL）渲染，还原旧版游戏 3D 星图；收录 5485 个有星门连接的星系（常规空间与波赫文）与 6989 条星门连接，虫洞空间不收录
- **2D / 3D 切换**：右下角按钮或 `V` 键，默认 3D（选择记在本机 `eve-map-view`）。2D 使用 SDE 的 `position2D`（游戏 2D 星图的平面排布，`map-data.json` 每个星系第 13 项），俯视、不能旋转、左键拖动平移；切换时星系平滑移动到新位置。光年、跳跃规划始终按真实三维坐标计算。曙光服星图没有 2D 数据，只有 3D（不显示切换按钮）
- **星系着色（12 种，分三组）**：
  - 基础：安全等级、星域、跳数距离（以选中星系为起点，默认吉他）、NPC 空间站数量
  - 势力：势力划分（ESI 主权）、军事指数（主权枢纽 ADM 1–6）、主权争夺（进行中的争夺战）、势力战争
  - 活动（过去 1 小时）：玩家击杀、NPC 击杀、跳跃、入侵
  - 颜色说明可点击高亮对应星系
- **星系详情**：安全等级、星域与星座、主权归属（游戏标志）、1 小时击杀与跳跃、恒星图标与行星数、NPC 空间站（官方中文名）、入侵与势力战争状态、相邻星系
- **星域详情**：安全等级分布、主要势力、游戏内官方中文简介，可一键高亮整个星域
- **我的位置**：绑定 ESI 后可定位到角色当前所在星系，并在其他星系详情中显示与自己的跳数
- **分享链接**：选中星系后地址栏为 `#map=星系ID`，打开链接直接定位；星系详情可跳转 zKillboard
- **路线规划**：ESI 路线接口，支持最短 / 安全优先 / 低安优先，路线绘制在星图上并逐跳列出，可复制整条路线
- **星系名称**：放大到中等距离起显示星系名（离屏幕中心近的优先，越近显示越多）；选中星系后，星门相邻和屏幕上附近的星系也显示名称
- **疑似会战**（`js/battles.js`，需要击杀记录服务 `/api/kb/battles`）：每 6 秒检查一次（与星图实时击杀同频），
  60 分钟内同一星系被击毁 ≥ 20 艘舰船（不含太空舱、NPC 击杀与 10M ISK 以下的击杀）即判定为疑似会战，
  按规模分为小型（20+）/ 中型（50+）/ 大型（100+）三档，以不同动画区分；击杀记录页可关闭弹出提醒。
  新会战在任意页面右上角弹出提醒（星系、击毁数、参战人数、损失、主要交战方），可跳到星图或按星系查看击杀；
  每场会战只提醒一次（按星系记在浏览器本地 6 小时，刷新页面、规模升级都不再弹），弹窗 5 秒后自动消失（鼠标停留时暂停）。
  星图上会战星系像选中星系一样高亮并按规模显示动画，与单次击杀的红色扩散圈区分
- **侧栏分区折叠**：星系着色 / 颜色说明 / 路线规划可分别折叠（默认只展开星系着色），折叠时标题右侧显示摘要（当前着色方式、高亮数量、路线跳数），
  状态保存在本地；在信息面板设为起点 / 终点或切换规划方式时自动展开路线规划
- **实时击杀推送**：需要击杀记录服务（`/api/kb/live`）。星图打开时每 6 秒取一次新击杀（R2Z2 实时收录，约 1 分钟延迟），
  发生击杀的星系闪烁 3 次（10 亿以上为金色大圈），同时以弹幕形式从星图上方滚过（舰船 · 受害者 · 星系 · 中间价估值），
  鼠标悬停暂停，点击定位星系并打开击杀详情；右下角闪电按钮开关，页面在后台时暂停；未部署击杀记录服务时自动隐藏
- **旗舰跳跃规划**（`js/jump-planner.js`）：航母、无畏、战力辅助舰、超旗、泰坦、黑隐、战略货舰、长须鲸，

## 模拟装配（v17）

- **入口**：顶部导航「装配」，地址栏 `#fit`；模块与数据（约 2.7 MB，gzip 后约 450 KB）在首屏后空闲时预加载
- **浏览器**：舰船 / 装备 / 弹药 / 无人机 / 植入体，按游戏市场分组浏览或中英文搜索；默认只显示能装到当前舰船的装备、已装武器可用的弹药；
  点击空槽位只看该槽位的装备，点击「装填弹药」只看该装备可用的弹药
- **装配**：高 / 中 / 低槽、改装件、子系统（T3 巡洋舰按子系统增加槽位与安装座），装备可切换离线 / 在线 / 激活 / 超载；
  无人机可设数量与激活数量（自动受带宽与同时操作上限约束）；植入体与增效剂，可一键导入当前角色的植入体
- **属性**：CPU / 能量栅格 / 校准值 / 安装座，炮台 / 导弹 / 无人机 DPS 与齐射伤害、伤害类型分布，护盾 / 装甲 / 结构抗性与 EHP，
  护盾自然回充与主动维修，电容稳定性（按游戏充能曲线计算），速度、起跳时间、跃迁速度、信号半径，锁定距离、扫描分辨率、最大锁定数、感应强度，货柜舱与估价（所选交易中心 / 全宇宙的最低卖价与最高收价）
- **检查**：资源、槽位、安装座超出，改装件尺寸，只能装特定舰船的装备，同类装备装配 / 激活数量上限，无人机挂舱与带宽
- **技能**：全部 5 级，或按已绑定 ESI 角色的技能计算，并列出装配需要但角色未达到的技能
- **保存与分享**：装配保存在本机浏览器；换船时当前没保存的装配记为这艘船的草稿（最多 30 艘），换到某艘船时载入它上次没保存的装配，没有则从空船开始，保存后清掉草稿；EFT 文本导入（游戏「复制到剪贴板」、Pyfa、zKillboard，中英文名称均可）与导出（英文名称，可导入游戏或 Pyfa）；
  分享链接 `#fit=…` 包含完整装配
- **装备状态**：主动装备默认激活，点状态按钮开 / 关（被动装备为在线 / 离线），右键切换超载，Shift 点击切换离线；「全部开启 / 全部关闭 / 清空装备」一键操作
- **铁骑舰载机**：航母 / 超级航母可在「无人机」标签添加舰载机，按满编中队计数，校验机库容量、发射管与轻型 / 支援 / 重型位，DPS 计入普通攻击与导弹技能
- **智能装配**（`js/fit-auto.js`）：选目标（输出优先 / 坦克优先 / 均衡 / 刷怪主动坦 / 风筝）与要求（最低 DPS、EHP、速度、电容稳定、预留扰频器和停滞网、
  坦克类型、武器类型、装备等级、预算），技能可选全 5 级或按 ESI 角色（只用角色能装的装备，属性按角色技能算）；
  用装配引擎给每种组合打分：先比较各种武器与弹药，再逐格贪心放入提升最多且装得下的装备，装不下时尝试加 CPU / 电网辅助装备，最后逐格替换优化，
  会配舰载机、需要装填的装备（电容注电器、辅助回充 / 维修器）也会自动装填；一般几秒内给出推荐方案与备选方案（DPS、EHP、速度、电容、估价），点「套用」载入；极化武器不参与；
  会读出舰船加成并识别定位（后勤 / 电子战 / 拦截 / 采矿 / 指挥 / 运输 / 能量战 / 隐形），先放好定位装备（远程维修与远程电容、多光谱 ECM 等电子战、
  扰频器 + 停滞网与拦截泡 / 扰断力场、采矿设备与采矿改良、指挥脉冲波、隐形装置、中和器），后勤按远程维修量、采矿按采矿量、运输按货柜容量打分；
  坦克类型与自修也参考加成（有护盾 / 装甲抗性或维修加成的船按对应方式配），受加成的武器优先；可在表单里改成「当普通战斗船」；
  候选装备包括护盾回充增量放大器、弯曲护盾 / 装甲强化器、护盾能源继电器、加强型舱隔壁、信号半径抑制装置、铁骑舰载机辅助单元，无畏 / 掠夺者自动装会战 / 堡垒模块，后勤旗舰装分流模块；
  可选交战目标（护卫 / 巡洋 / 战列 / 旗舰）与交战距离（5 / 20 / 50 / 100 km），输出按对目标的有效 DPS 计（`fit-engine.js` 的 `appliedDps`：
  炮台按跟踪、信号分辨率、最佳射程与失准范围算命中，导弹按爆炸半径 / 爆炸速度与飞行距离，无人机按信号比例与速度，岗哨按炮台公式），
  武器按弹药尺寸 + 射程 + 跟踪分族比较（旗舰反旗舰炮与高角炮、长 / 短射程炮分开），弹药逐种试装取有效 DPS 最高的；
  同分组、属性完全相同的装备 / 弹药只留最便宜的，搜索完再逐件试同族更便宜的装备（整套得分合计下降不到约 0.2% 才换），效果相同时总是取便宜的
- **智能植入体**：装配页「智能植入体」（或植入体栏的「智能推荐」）保持装备不动，按目标给当前装配推荐 1–10 号槽植入体；智能装配勾选「同时推荐植入体」时，每个方案配好装备后再做同样的推荐。
  逐个试装市场上有售、在植入体预算内（按 ESI 角色时还要求技能够）的植入体，只留能提升得分的；「最佳」按提升从大到小逐槽挑预算内最好的，
  另对每个套装（水晶、极乐、蝰蛇等，低 / 中 / 高级，占 1–6 号槽）逐件加入，2 件到整套的每种件数都配上其余槽位的最佳植入体一起比较
  （同套每多装一件，套内其他件的效果按套装系数叠乘放大，由装配引擎按游戏规则算），预算买不起整套时也会比较凑几件的方案；
  「性价比方案」每槽取效果达到最佳 70% 的最便宜植入体；另列出「套装方案」或「不用套装」的最佳方案方便对比。每个植入体标出单独装上时的作用（如 DPS +5.0%），
  方案显示相对不装植入体的属性变化与估价（全服均价），点「套用」替换当前植入体。运输船打分加入起跳时间，导航类植入体也会被考虑
- **击杀记录装配**（`js/fit-kb.js`）：列出当前舰船最近 1 / 3 / 7 / 14 / 30 天阵亡时的装配（击杀记录服务 `/api/kb/shipfits`，最多分析最近 300 次损失，
  首次查询从 ESI 取击杀原文并存库），只看装备相同的合并为一组，显示出现次数、占比、最近时间与平均损失，套用时装填最常见的弹药与无人机
- **计算引擎**（`js/fit-engine.js`）：与游戏相同的 dogma 规则——属性基础值依次应用预赋值、预乘、预除、加、减、后乘 / 后除 / 百分比、后赋值，
  不可叠加属性对装备来源的乘法修改施加叠加惩罚；加成来自 SDE 效果的 modifierInfo，推进器提速、子系统槽位、导弹 / 无人机技能伤害、专业化射速等少数效果单独实现

装配数据由 `server/build_fit_data.py` 从 SDE（JSON Lines 版）生成：


### 深渊装备自定义属性（v61）

- 能突变的装备（有对应突变质体的原装备，或已经是深渊装备）在装配行上有「突变」按钮，打开后选突变质体，逐项拖动滑块或输入数值，

- **材料效率影响**：蓝图 ME 0–10 各自的材料费、单个成本、利润与比当前省多少（流程太少看不出差别，至少按 10 个流程算）
- **研究与拷贝**（原图）：ME / TE 研究到目标等级的时间与估算费用、研究后每流程省多少材料、几个流程回本；拷贝 N 份 × M 流程的时间与费用。
  时间 = 蓝图研究基础时间 × 等级倍数（105 / 250 / 595 / 1414 / 3360 / 8000 / 19000 / 45255 / 107700 / 256000）÷ 105 × 技能（冶金学 / 研究 / 科学 −5%/级、高级工业理论 −3%/级）× 设施；
  费用按产品 EIV × 2% × 时间倍数 ×（研究 / 拷贝指数 + 设施税 + SCC）估算。基础时间来自 SDE（`industry-data.json` 的 `res`）
- **制造规划**（`#ind/plan`，保存在本机）：计算器 / 我的工业 / 库存可造里「加入规划」，多个产品一起算：每项可改流程数与 ME / TE；
  组件与中间产品可点选自制，按层级逐级展开汇总；库存可选不扣 / 我的资产（ESI，`esi-assets.read_assets.v1`）/ 粘贴清单（游戏里复制的物品列表），先抵扣组件再抵扣材料；
  产线启动清单（每个任务的流程数、ME / TE、时间、安装费、哪条线什么时候开，标出整流程多出的组件）与按制造 / 反应产线数排的时间轴（先造最深层组件，一层完成再开下一层）；
  汇总材料、安装费、发明、卖出所得、总利润与全部完成时间；购物清单与启动清单可复制
- **库存可造**（工业清库）：按资产或粘贴清单反推能造什么——「直接能造」（最多流程、用掉的库存价值、利润）与「差一点能造」（库存覆盖一个流程材料价值一半以上，列出缺什么、补齐要花多少）；只算蓝图能正常获得的产品
- **我的工业**：蓝图按自身 ME / TE 算单个成本、每流程利润与每小时利润，按每小时利润排序，可直接加入规划
- **利润排行**：绑定 ESI 后可勾选「只看技能够造」（技能设为读取角色时，含发明技能）与「只看我有的蓝图」（T2 有对应 T1 蓝图也算；曙光服没有蓝图权限）

### 制造：综合评分、NPC 蓝图、粘贴导入、按人物产线（v35）

- **综合评分**（利润排行）：价格先读击杀记录服务的交易中心快照（`/api/v1/hubs/arbitrage`，主交易中心全部物品的卖价 / 收价 / 30 天日均成交，每 30 分钟汇总），
  所有产品都按交易中心价格算，不再只靠全服均价；实时行情（计算器、精算前 30 名）仍优先。评分 0–100 = 每小时利润 40% + 日均成交额 30% + 利润率 20% + 买卖价差 10%
  （利润与成交额按对数刻度），日均成交不到 1 个的按成交量开方打折、没有成交的为 0；可按评分 / 日均成交排序，筛选「日均成交至少」「综合评分至少」。快照读不到时退回原来的全服均价排行
- **NPC 蓝图**（`#ind/npc`）：NPC 军团在自家空间站按固定价格出售的 1726 种蓝图原图，可搜索、按势力 / 星域筛选，列出价格、出售军团与星域；
  计算器的蓝图卡片多一栏「NPC 出售」（价格与出售军团）。数据 `npc-bp.json`（约 120 KB）由 `build_npc_bp.mjs` 从 SDE `npcCorporations.corporationTrades` 生成
- **粘贴导入游戏蓝图**（我的工业）：曙光服登录不支持蓝图权限，或不想授权时，从游戏工业窗口 / 机库复制蓝图列表粘贴进来；每行取最长匹配的蓝图名（中英文），
  后面的数字依次作为 ME、TE、剩余流程，带「原图」或没有流程数的算原图，「×3」为数量。按服务器保存在本机（`eve-industry-bps-<服务器>`），
  ESI 读不到蓝图时「我的蓝图」和利润排行的「只看我有的蓝图」改用导入的列表
- **按人物分配产线**（制造规划 · 产线时间轴）：选「按人物」时读取每个已绑定角色的技能（产线 = 1 + 大规模生产 + 高级大规模生产；反应 = 1 + 大规模反应 + 高级大规模反应，需要反应学）
  与进行中的工业任务（产线到任务结束才空出来），时间轴每行是「角色 · 制造 N」，已有任务画成灰色条，启动清单写明哪个角色哪条线；读取其他角色时用各自的令牌（单独刷新）
- **分批**：规划里每个产品可填「分批」，拆成 N 个任务放到不同产线同时造（时间与安装费按流程数分摊）
- **发明进度**：规划里有 T2 发明的产品时多一张卡片，填已发明次数和成功张数，显示实际成功率与预计成功率、还差几张拷贝，以及约 95% 把握还要再发明几次、花多少
- **行星工业联动**：购物清单里的行星产品（P0–P4）旁有「行星工业」按钮，跳到行星工业规划（`#pi/<物品ID>`）直接规划这种产品；清单标题汇总要买的行星产品种类与金额

制造数据由 `build_industry.mjs` 从 SDE 生成：

```bash
node build_industry.mjs <SDE 解压目录>   # 输出 eve-overview-clone/industry-data.json 与 skill-data.json（res：蓝图 → [ME 研究, TE 研究, 每流程拷贝] 基础秒数）
node build_npc_bp.mjs <SDE JSONL 解压目录>   # 输出 eve-overview-clone/npc-bp.json（NPC 出售蓝图）
node build_volumes.mjs <SDE JSONL 解压目录>  # 输出 eve-overview-clone/type-volume.json（物品包装体积，倒卖运费用）
```

## LP 商店（v24）

- **入口**：顶部导航「LP 商店」，地址栏 `#lp`（`#lp/store/<军团ID>`、`#lp/rank`、`#lp/mine`）；数据约 500 KB（gzip 后约 80 KB）首次进入时加载
- **LP 商店**：按势力浏览 181 个 NPC 军团的兑换项，计算 ISK/LP =（产物价值 × (1 − 税费) − 所需物品成本 − ISK 费用）÷ LP；
  蓝图拷贝按（产物价 − 材料价）× 数量估算（材料效率 0）；可筛选、按 ISK/LP / 利润 / LP 排序，点击行展开花费明细与可兑换的军团，前 25 行显示吉他日均成交量
- **估价设置**（保存在本机）：产物按吉他卖单 / 收单 / 全服均价，材料按吉他卖单 / 收单 / 全服均价，卖出税费 %；吉他行情逐个物品读取并缓存，读取中先用全服均价（标 ≈）
- **全服排行**：所有兑换项（按 offer 去重）按 ISK/LP 排行，可按势力筛选；默认全服均价估算，前 40 名可用吉他行情精算
- **复制采购清单**（v60）：展开兑换项后可填兑换次数（读过「我的 LP」时可一键填「按我的 LP 最多 N 次」），按钮复制「兑换所需物品」、
  蓝图兑换项的「制造材料」（材料效率 0，按兑换得到的全部流程）或「全部（合并同类）」，格式为每行「物品名<Tab>数量」，
  粘贴到游戏「市场 → 批量购买」即可一次买齐；同时显示所需的 LP、ISK、AK 合计。物品名为简体中文官方名，需游戏客户端也是简体中文
- **我的 LP**（ESI）：角色在各军团的 LP 余额与按最佳兑换估算的价值；需要 `esi-characters.read_loyalty.v1` 权限（需在 esi-service 配置与 CCP 开发者后台开通，并重新绑定）
- **侧栏**：三个页面的导航、搜索军团 / 兑换品、按势力浏览军团；可收起（`[`），手机端为抽屉

LP 数据由 `build_lp.mjs` 生成（兑换项来自 ESI，名称与蓝图材料来自 SDE）：

```bash
node build_lp.mjs <SDE 解压目录>   # 输出 eve-overview-clone/lp-data.json
```

切换顶部导航时各页面保持原样：离开时记住地址栏与滚动位置，切回来恢复，页面不重新渲染（筛选、展开的行、输入框都保留）。

## 宁静 / 晨曦服务器切换（v25）

顶栏右侧的服务器状态就是切换按钮，默认宁静服（国际服），可切到晨曦服（国服）。选择记在浏览器里，切换后整页刷新。

- **ESI**：晨曦服请求 `ali-esi.evepc.163.com`（`datasource=serenity`），市场订单、历史、均价、主权、入侵、角色数据等都换成晨曦数据
- **登录**：晨曦服用网易 SSO（`login.evepc.163.com`）。网易没有开放第三方应用申请，和其他国服工具一样复用官方 ESI 网页自带的应用（Client ID `bc90aa496a404724a93f41b4f4e97761`，回调 `https://ali-esi.evepc.163.com/ui/oauth2-redirect.html`，另带网易必填的 `realm`、`device_id`）。登录后浏览器停在网易 ESI 页面，复制地址栏粘贴到绑定框第 2 步即可，授权码几分钟内失效
- **换令牌**：网易换令牌接口不允许跨域，由 `esi_service.py` 的 `POST /api/esi/sso/token?server=serenity` 原样转发（只转发必要字段，校验 client_id，每 IP 每分钟 20 次，不记录内容）。不需要额外配置；以后有专属应用时可在 `config.json` 的 `"serenity"` 下填 `client_id` / `redirect_uri` 覆盖
- **本地数据**：两个服务器的令牌、建筑缓存、价格缓存分开保存（晨曦服的键名加 `serenity:` 前缀），切换不会互相覆盖；共享的玩家建筑缓存服务器端也分文件
- **图片**：物品图标两服通用；人物头像、玩家军团 / 联盟图标晨曦服取自 `image.evepc.163.com`
- **LP 商店**：晨曦服读 `lp-data-serenity.json`（`node build_lp.mjs <SDE目录> --serenity` 生成）
- **击杀记录**：国服击坠榜（beta.ceve-market.org）的数据接口有 CrowdSec 人机验证、请求加密且不开放跨域，本站不抓取，只外链过去（击杀页入口、个人中心「战斗记录」跳到 `pilot/<角色ID>`）
- **不支持**：zKillboard 与本站击杀记录服务只收录宁静服，晨曦服下击杀记录页、战斗记录、舰船近期损失、星图实时击杀与击杀列表、击杀装配、制造的蓝图合同价不可用

### 击杀预警（v57）

- 右上角铃铛打开设置，**默认关闭**；开启后按角色当前所在星系（`/location/` 每 30 秒读一次），检测周边 N 跳内的击杀（默认 3 跳，可设 1–10，星门图广度优先搜索；虫洞等无星门星系只监控本星系）
- 数据：宁静服用击杀记录服务 `/api/kb/live`（每 6 秒，第一次只取游标不提醒旧击杀；实时缓冲里新增了 `hash` 字段）；
  晨曦 / 曙光没有实时击杀源，用 ESI `/universe/system_kills/`（各星系过去 1 小时击杀数，约每小时更新）与上一次的差值判断，每 5 分钟检查，没有具体击杀邮件
- **游戏内邮件**（默认开）：给自己发 EVE 邮件（`esi-mail.send_mail.v1`，基础权限里已有），正文列出星系（`showinfo:5//星系ID` 链接）、跳数、舰船、受害者、价值、攻击者数，
  附 `killReport:ID:HASH` 击杀报告链接，游戏里点开即显示 KM。多条合并成一封，两封至少隔 60 秒；发送失败（多为频率限制）时多等 1 分钟。
  多个标签页同时打开时用 localStorage 选一个「领头」标签页发送，避免重复
- **网页醒目特效**（默认关）：屏幕边缘红色闪烁 + 右上角预警卡片（本星系的击杀卡片底色更红），点击打开击杀详情，45 秒后自动消失；可选提示音（WebAudio）；遵循「减少动态效果」系统设置
- 可选「包括太空舱」；面板里有「测试网页特效」「发送测试邮件」和最近 30 条预警记录；铃铛上的绿点表示正在监控
- 网页需要保持打开；浏览器会把后台标签页的定时器降到约每分钟一次，预警可能延迟

#### 人物关注（v58）

## 行星工业（v19）

- **入口**：顶部导航「行星工业」，地址栏 `#pi`；数据（约 500 KB，gzip 后约 150 KB）首次进入时加载
- **方式**：自产（采集）或买料加工（见下）
- **地区**：整个星域，或某星系周边 0–5 跳；可按高安 / 低安 / 00 过滤；
  或虫洞：按等级（C1–C6、C13、席拉、漂流者，综合该等级所有虫洞，行星分配取一个示例洞），或指定某个虫洞（J123456）。
  虫洞之间没有固定通道，行星分配只用这一个洞
- **角色**：角色数、每角色行星数（星际整合 + 1）、指挥中心等级（指挥中心升级），按等级计算 CPU / 电网
- **一键规划**：对每种 P1–P4 产品求最优分配并按日净收益排序（也可指定产品）：
  - 采集星：同一种 P0 用 2 个采集控制器、电网允许的最多采集头，就地加工成 P1
  - 单星 P2：两种 P0 都能在同一类行星采集时，一颗行星直接产出 P2
  - 采集 + 工厂星：按需求比例分配各 P1 的采集星数量与工厂星数量，多出的 P1 直接出售
  - 采集兼工厂（混合）：不单开工厂星，把加工设施平摊到几颗采集星上——采集星卡在电网（采集头 110 CPU / 550 电网）、CPU 富余，
    少放一两个采集头就能放下高级工厂；P4 只让贫瘠 / 温和行星兼工厂（高科技工厂）
  - 直接出口 P0：个别 P0（如长英矿物岩浆、重金属）比加工后的 P1 值钱，不建基础工业设施
  - 行星够不够分：几种殖民地抢同一类行星时（如单个虫洞），按 Hall 定理检查每类行星「数量 × 角色数」的容量，
    分配时贪心分不完再用最大流重新分配
  - 收益按吉他卖单或收单价，扣除海关进出口税（税率可调）；采集速度按资源丰度估算（每个采集头每小时 300 / 500 / 750 单位）
- **买料加工**：从吉他买入半成品，在工厂星上加工成更高级产品卖出；比较买到哪一级（如买 P3 做 P4、买 P2 做 P3 再做 P4）。
  除 CPU / 电网外受发射平台容量限制（一个补货周期的原料或产物放得下，10,000 m³ / 个），放不下就加发射平台，
  每个发射平台带一组完整加工链；原料价可选直接买卖单或挂收单，扣原料进口税与产品出口税。
  前 20 名按吉他近 30 天日均成交量核对：产品卖出、每种原料买入各不超过日成交的设定比例（「成交上限」5% / 10% / 20% / 不限，默认 10%），超出则减少行星数，
  列表里标「限成交量」。这类产品加角色也不会多赚，所以结果顶部另给「多产品组合」（v85）：按每颗行星日收益从高到低，
  把用不满的行星依次分给下一种产品，算出全部殖民地的组合总收益（各产品的原料成交量上限分别计算，不合并）
- **行星分配**：以覆盖所需行星类型最多的星系为中心，由近到远给每个角色分配具体行星（同一角色不重复使用同一颗行星）
- **殖民地模板**：每种角色生成游戏内模板 JSON（设施、链接、路由），显示 CPU / 电网占用；
  「复制模板」后在游戏里「导入与导出 → 从剪贴板载入」，或下载 .json 放进 `文档\EVE\PlanetaryInteractionTemplates`。
  ESI 只有读取殖民地的接口，不能写入模板
- **模板预览与编辑**（`js/pi-editor.js`、`js/pi-globe.js`）：纯黑背景上按 La / Lo 摆放设施（正交投影，拉近后近似平面），
  设施用游戏行星界面风格的图标（`assets/pi/*.svg`），采集控制器外圈按头数显示采集球（`assets/pi/head.svg`，照游戏内采集头样式绘制），链接显示长度并有流动光点，
  拉近后显示设施名称，悬停显示配方，选中设施时动画显示原料 / 产物路由。
  可拖动 / 添加 / 删除 / 复制设施、连接或断开链接（L 键）、链接升级、配方与采集头数、行星类型、直径与指挥中心等级；
  CPU / 电网按游戏公式实时计算（链接按弧长 × 行星半径计费）。导入检查与游戏一致：设施间距 ≥ 0.012 弧度（更近会被拒绝导入）、
  路由最多 7 个设施、链接流量不超过容量（1250 m³/h × 2^等级）、资源不超出。路由按链接自动生成；导出时 `Diam` 写成小数，与游戏一致。
  页头「模板编辑器」可从空白开始或导入已有模板 JSON

行星工业与化矿数据由 `build_pi.mjs`、`build_reprocess.mjs` 从 SDE 生成：

- 名称对照用市场物品目录（`catalog.json`），不在市场上卖的物品估不了价
- **交易税费（全站共用）**：市场详情的「倒卖利润（税后）」卡片、个人中心资产估值、估价页用同一套设置（`trade-fees.js`，保存在本地）。
  技能默认全部 5 级，可自定义（统一等级 + 逐项）或读取已绑定角色的技能；市场详情点利润卡片、资产页点税费按钮打开设置弹窗。
  倒卖利润 = 最低卖价 × (1 − 销售税 − 中介费) − 最高买价 × (1 + 中介费)，即挂收单买入、挂卖单卖出的每件税后利润，并显示利润率
- **左侧设置**分三块折叠面板，标题行直接显示当前结果：「技能」（交易与化矿共用，默认全部 5 级，可统一调整或逐项改，也可读取已绑定角色）、
  「交易税费」「化矿设置」
- **交易税费**：销售税 = 7.5% × (1 − 会计学 11%/级)；中介费在 NPC 空间站 = 3% − 经纪人关系学 0.3%/级 − 派系声望 × 0.03% − 军团声望 × 0.02%（最低 1%），
  玩家建筑直接填建筑中介费率。市场与化矿估价的总价卡片和合计行都给出税后金额：卖给收单只扣销售税，挂卖单再扣中介费；复制结果也带税后
- **化矿估价**：结果上方切换「市场估价 / 化矿估价」。按 `reprocess-data.json` 算每件物品的再处理产物，产物按同一交易中心挂单计价，
  列出化矿价值、原物品直接卖收单的价值和建议（化矿 / 直接卖），以及合计产物清单；不足一批的零头、不能化矿的物品单独提示
  - 矿石 / 冰矿 / 卫星矿化矿率 = (50 + 改装件 T1 1 / T2 3) × (1 + 安全等级 低安 6% / 00 与虫洞 12%) × (1 + 阿塔诺 2% / 塔塔拉 5.5%)
    × (1 + 提炼学概论 3%/级) × (1 + 提炼效率理论 2%/级) × (1 + 对应矿石处理技能 2%/级) × (1 + 植入体 RX-801/802/804 1/2/4%)；
    NPC 空间站固定基础 50%。装备等其它物品 = 50% × (1 + 碎铁处理技术 2%/级)
  - 技能面板只列出当前物品用到的矿石处理技能；用角色技能时，有 `esi-clones.read_implants.v1` 会自动带上身上的提炼植入体；
    可填再处理税，所有设置保存在本地

### 本站深渊估价模型与资产估价（v86）

- **优先级**：有 `item_id` 的装备先用 MutaMarket 已有的估价（只读，不导入）；MutaMarket 没有的、以及装配里自定义的属性，用本站模型（`POST /api/v1/abyssal/estimate`）
- **模型**：算法照搬 [MutaMarket 估价器](https://github.com/MutaMarket/MutaMarket)（MIT 许可，`src/estimator/forest.rs`）——每种深渊装备一个随机森林回归（自助采样 CART，每次分裂考虑全部特征，最大深度 20，每叶至少 2 个样本），
  在 ln(1+价格) 上拟合，5 折连续分组交叉验证给出 R² / MAE / NMAE；特征为 MutaMarket 每个类型的属性列表（去掉 DPS 之类的派生属性）。纯 numpy 实现（`kb_service.py` 的 `Forest` / `AbyssalModel`），训练在子进程里跑
- **数据与差别**：MutaMarket 用的是会员级的真实成交记录，训练好的模型也只在他们的数据库里，所以本站改用 EVE Ref 公开合同快照（`refresh_bp_contracts` 已在下载）中只卖一件深渊装备的合同：
  到期前消失的按疑似成交、权重加倍，仍在挂的按挂牌价（所以偏向挂牌价）；树 100 棵（他们 300），没有用原装备市场价做锚点。数据存 `abyssal_contracts`（保留 180 天），模型存 `abyssal_models`，每 6 小时重训，少于 50 条的类型不建模；
  首次只有挂牌数据，大约 40 多种常见类型有模型，随着成交数据积累会变准。统计见 `GET /api/v1/abyssal/estimator`
- **装配**：「改属性」默认只有属性调整和参考估价卡片（套用在售装备且属性未改时取该件的 MutaMarket 估价，否则按当前属性用本站模型，悬停看数据量与误差）；点「深渊市场在售」才读取同类在售装备并以卡片列出，可对比当前属性、一键套用
- **资产**：资产估值页有深渊装备时多一张「深渊装备」卡片，默认不估价；点「估价深渊装备（N 件）」后开启（记在本机，可「关闭估价」），
  合计深渊参考估价（不计入市场估值）并注明 MutaMarket / 本站模型各几件，空间站明细里每件深渊装备旁显示估价与来源

## 交易中心比价（v86）

- 市场详情的「交易中心比价」标签（`js/hub-compare.js`）：五大交易中心（宁静 / 晨曦：吉他、艾玛、多迪谢、伦斯、赫克；曙光为对应的五个）空间站内的最低卖价、卖单量、最高收价、收单量，以及整个星域近 30 天日均成交量与成交额，最好的卖价 / 收价高亮
- **倒卖利润（税后）**：四种方式切换——卖单收 · 收单出、收单收 · 收单出、卖单收 · 卖单出、收单收 · 卖单出。
  「卖单收」直接买 A 的最低卖单，「收单收」按 A 最高收价挂收单（付中介费）；「收单出」直接卖给 B 的最高收单（付销售税），「卖单出」按 B 最低卖价挂卖单（付销售税 + 中介费）；A = B 为本地倒卖。
  税率按全站共用的技能与税费设置（会计学、经纪人关系学、声望 / 建筑税，点按钮调整）
- **结合成交量**：可做数量按两端取小——直接成交按最优价 5% 以内的订单深度，挂单按该星域日均成交的 10%；预计利润 = 每件利润 × 可做数量。可按预计利润 / 利润率 / 每件利润排序，未计运费与风险
- 打开标签时才查 ESI（每个中心一次订单 + 一次历史，缓存 5 分钟）；伊甸币这类全服统一市场的物品不适用
- 挂单价要在该星域 30 天成交均价附近才算：收单价低于均价 60%、卖单价高于均价 140%（钓鱼单、没人成交的挂单）的路线不列出（v89）

## 快递合同

- **入口**：顶部导航「快递」，地址栏 `#courier`；左侧栏筛选，点合同看详情
- **数据**：宁静服读击杀记录服务 `/api/kb/couriers`（EVE Ref 全服公开合同快照里的快递合同，约 30 分钟更新，一次请求）；

- **路线**：星门图广度优先搜索。「安全优先」时起终点都在高安就只走高安，走不通再用最短路线；取货跳数从手动填写的星系或角色当前位置算起
- **评分**：综合分（0–100）= 每跳收益（报酬 ÷ 取货 + 运送跳数）、报酬、取货距离、安全四项加权，侧重可选平衡 / 收益 / 安全 / 就近；
  风险看途经低安 / 00 星系、抵押金额、名称不公开的玩家建筑（可能无法停靠）、大额抵押 + 建筑终点、完成期限
- **筛选**：路线安全（不限 / 不进 00 / 仅高安）、舰船容量、最低报酬、最高抵押、取货距离、起点星域、隐藏不公开建筑，搜索星系 / 空间站 / 星域
- **推荐用船**：每份合同按体积、抵押和路线安全推荐一艘船和一套装配（列表「推荐用船」列，详情里有装配、容量占比、有效血量、起跳时间和推荐理由）：
  - 全高安：抵押 ≥ 3 亿用封锁运输舰 / 深空运输舰，否则用 T1 工业舰，装不下用货舰（装得下时尽量多装强化舱隔壁）
  - 经过低安 / 00：侧栏可选跳货（默认）/ 封锁运输舰 / 深空运输舰 / 能装下的最小船；经过 00 时不推荐货舰
  - 种族偏好：自动（装得下的船里取有效血量最高的）或指定种族
  - 跳货另算跳跃路线（跳跃引擎校准理论 5 级，10 光年）：起点在高安先走星门到最近的低安，终点在高安跳到附近再走星门，显示跳跃次数、光年和燃料

### 击杀记录服务部署

```bash
# 首次启动会导入最近 30 天的 EVE Ref 每日存档（约 50 万条，约 10 分钟），之后持续收录新击杀
python3 server/kb_service.py --db /opt/eve/kb/kb.sqlite --port 8291 --days 30
```

- **占用**：数据库约 **10 MB / 天**（30 天约 310 MB），超出保留期的击杀每小时自动清理并把空间还给磁盘，体积不会持续增长
- **30 天以前**：带筛选条件（人物 / 军团 / 联盟 / 舰船 / 地点）的列表翻完本地记录后，服务会接着实时查询 zKillboard，
  同样按吉他中间价估值，结果只放内存、不写数据库，列表中以分隔行标出。zKillboard 每个查询最多翻 100 页（2 万条），
  活跃的大联盟可能查不到 30 天以前；没有筛选条件的全局列表 zKillboard 不支持，只显示保留期内的记录
- 本地只保存统计所需的字段和玩家攻击者，不存击杀邮件原文；打开击杀详情时按需向 ESI 获取（内存缓存最近 500 条）
- 旧版（v10 首版，含原文）数据库在启动时会自动精简一次，期间需要约等于新库大小的临时空间

- 历史：EVE Ref 每日击杀存档（每 6 小时检查新的一天，同时补齐重启期间的缺口）
- 实时：zKillboard [R2Z2](https://github.com/zKillboard/zKillboard/wiki/API-(R2Z2)) 顺序推送，击杀发生后约 1 分钟入库；
  进度保存在数据库，重启后从上次位置继续。RedisQ 已于 2026-05-31 停用（`--live redisq` 等同 `r2z2`）。
  R2Z2 不可用时自动改为轮询各星域最新击杀（每 5 分钟一轮，受 zKillboard 缓存影响最多延迟约 1 小时）
- 价格：每小时下载伏尔戈全量订单（约 400 页）计算吉他中间价；排行榜与首页统计每 9 分钟后台预计算
- nginx 将 `/api/kb/` 与开放 API `/api/v1` 反代到 8291（见 `server/eve.navexor.top.conf`，`/api/v1` 需传 `X-Real-IP` 以便按 IP 限流）；建议用 systemd 托管：

```ini
[Unit]
Description=EVE Market Tool KB service
After=network-online.target

[Service]
ExecStart=/usr/bin/python3 /opt/eve/server/kb_service.py --db /opt/eve/kb/kb.sqlite --port 8291 --days 30
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
```

- **虫洞类型**：全部 102 种虫洞代码的出现位置、通往、存活时间、总质量、单次质量、质量回复、能否作固定出口，按代码搜索、按通往筛选

  按总质量 ±10% 随机算每一步后的剩余质量区间、状态（稳定 / 减弱 / 临界）、是否可能已塌、还有几艘船在对面，超过单次质量会标出；记录保存在本地
- **席拉连接**（宁静服）：EVE-Scout 公开接口（`api.eve-scout.com/v2/public/signatures`，允许跨域，5 分钟更新）的席拉 / 图尔努尔实时虫洞：两端信号、对面星系与安全等级、类型、最大船型、剩余时间；
  输入所在星系后按星门跳数排序，找最近的入口
- **数据**：`build_wormholes.mjs` 从 CCP SDE 生成星系等级（星系 → 星座 → 星域的 wormholeClassID）、天象（次级恒星类型）、行星 / 卫星与虫洞类型属性（属性 1381–1385）；
  各星系的固定出口与虫洞出现在哪些等级不在 SDE 里，取自 anoik.is 的社区静态数据
- **接口**：`GET /api/v1/wormholes/activity?days=` 与 `GET /api/v1/wormholes/systems/{id}`（击杀记录服务，见 api.html）

## 主权规划（v81）

顶部导航「主权」（`#sov`，星系 `#sov/sys/<id>`，总览 `#sov/overview`，我的主权设施 `#sov/esi`）。数据来自最新 SDE（`sovereigntyUpgrades`、`planetResources`），页头显示 SDE 版本。

- **选星系**：搜索框可搜星系 / 星座 / 星域；星座和星域可按主权联盟筛选后整片加入（只含可建主权中心的星系）。主权归属：宁静服读 `/sovereignty/systems`（同时显示军事 / 工业 / 战略等级、是否首都），国服读 `/sovereignty/map/`
- **资源**：电力 = 恒星电力 + 装了轨道天钩的气体 / 风暴 / 等离子行星；劳动力 = 天钩的温和 / 贫瘠 / 海洋行星；冰体 / 熔岩行星天钩产超离子冰 / 岩浆气。每颗行星可勾选是否有天钩
- **升级件**：按优先级排列（可上下调整、开关、删除），同一互斥组只能装一个；按优先级依次分配电力和劳动力，放不下的标「资源不足」并继续给后面的。电力监控部门 / 劳动力机械工具的产出只给优先级更低的升级件用
- **劳动力运输**：每个星系可设导出（目的地 + 数量，不超过本星系天钩劳动力）/ 导入 / 中转；沿星门找路线，途经星系必须在规划里且设为中转；每个星系最多 3 个导入来源。不合规的设置在星系列表和总览里标出
- **一键规划**（v92）：只需选各星系装哪些天钩、哪些升级件，点侧栏「一键规划」自动配好其余部分——产出件排到最前；缺电且没装产出件时加能补足的最低级电力监控部门；
  劳动力缺口按「可选来源最少的先处理」，沿星门找规划里有富余的星系导出（优先一次补足的最近来源，可借道有富余的星系，否则取富余最多的，最多 3 个来源），途经星系自动设为中转；
  运输后仍不够且电力有富余时加劳动力机械工具。电力监控部门按「不加 / 本星系劳动力够付才加 / 缺电就加」三种策略都试，取上线升级件最多的方案。
  结果卡片列出运输路线、自动加装的升级件（表格里标「自动」）和仍缺电 / 缺劳动力的星系，可撤销；勾选「改动后自动」后每次改天钩或升级件都会重新规划（此时劳动力运输只读）
- **燃料**：每个星系与整个规划的试剂每小时产出 / 消耗 / 净值、30 天消耗量与体积、启动燃料合计，30 天消耗按吉他最低卖价估 ISK
- **我的主权设施**（宁静服）：新版 ESI `/corporations/{id}/structures/sovereignty-hubs[/{id}]` 与 `/skyhooks[/{id}]`（兼容日期 2026-08-18，权限 `esi-structures.read_corporation.v1`，需董事等军团职位）。按星域列出主权中心的电力 / 劳动力分配、升级件与上线状态、燃料仓剩余可烧时间、劳动力运输与易损窗口，以及天钩的产出状态与试剂库存。「导入到规划」把这些星系、升级件顺序和运输设置转成规划（有本军团天钩数据的星系按实际天钩勾选行星）
- 绑定框里的「主权设施」权限默认不勾、只在宁静服显示：CCP 开发者后台的应用要先加上 `esi-structures.read_corporation.v1`
- 规划存在 localStorage `eve-sov-plan`，「总览」可导出 / 导入 JSON 文件

## 开放 API（v23）

击杀记录服务同时提供对外的只读接口 `/api/v1/`，文档为站点根目录的 `api.html`（页面顶部「API」按钮打开，每个接口都能直接「试一试」）。

- 免注册、免密钥，允许任意来源跨域（CORS `*`），返回 JSON；出错统一为 `{"error": {"code", "message"}}`
- 按 IP 令牌桶限流：每分钟 1000 次（`API_RATE`），阵亡装配一次消耗 10 次、战场统计与利润排行 5 次（`API_COST`）；响应头带 `X-RateLimit-Limit / Remaining`，超限返回 429 与 `Retry-After`
- 接口：`/status`、`/prices`（卖 / 收默认吉他，`hub` 可选四族贸易中心或 `all` 全宇宙；另有全服均价 / 本站估价）、`/blueprints/prices`、`/kills`（只查保留期内，不转向 zKillboard）、`/kills/live`、`/kills/top`、
  `/kills/{id}`、`/stats/summary`、`/battles`、`/battle-report`、`/leaderboard`、`/entities/{kind}/{id}`、`/search`、`/ships/{id}/fits`；`/api/v1` 返回接口目录
- 制造接口（`Industry` 类，公式与 `js/industry.js` 一致，技能按全 5 级）：`/industry/search`、`/industry/blueprints/{product}`、
  `/industry/cost`（材料用量、安装费、发明分摊、合同拷贝、税费后利润与时间；可选星系、设施、改装件、税率、ME / TE、解码器）、
  `/industry/profits`（利润排行，默认过滤有价无市，消耗 5 次）、`/industry/systems`（成本指数）；
  读取前端目录的 `industry-data.json` 与 `map-data.json`（`--industry-dir`，默认依次找 `--static`、仓库前端目录、`/opt/eve/dist`），成本指数每小时从 ESI 更新

## 数据说明

## 与原站的已知差异

- 在线人数仍为页面快照（原站实时刷新）
- 合同相关 Tab 仍是原页面的占位入口；可通过右上角“合同估值”打开已接通的合同工具
- ESI 授权需要在官方 [EVE Developers](https://developers.eveonline.com/) 注册应用，将绑定弹层提示的回调地址填入应用配置，再粘贴 Client ID。页面会生成授权链接，登录完成后把地址栏中的完整回调地址粘回工具。OAuth 使用纯前端 PKCE：授权码换令牌、刷新令牌都由浏览器直接请求 `login.eveonline.com`，access/refresh token 只存储在浏览器 localStorage，本站服务器接触不到（可在开发者工具「网络」面板核对：带令牌的请求只发往 `login.eveonline.com` 与 `esi.evetech.net`）。`server/esi_service.py` 只提供公开的应用配置（Client ID、回调地址、权限列表）与公开玩家建筑名称缓存，不需要也不应配置 Client Secret。解绑会清除令牌，也可在 CCP 第三方应用管理页随时撤销授权
- 省略号菜单、更多菜单的下拉项为快照可见项
